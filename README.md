# POCUS 2027 news

News posts for the "News & updates" page on neonataltraining.org.

The page reads `news.json` from this repository and shows the posts, newest first. To add a post, add an entry to `news.json` with `date` (YYYY-MM-DD), `title`, `text` and optionally `link` and `linkText`.

## Sponsors

The "Our sponsors" page reads `sponsors.json`. Each sponsor has `name`, and optionally `logo` (image URL, e.g. a file in the `logos/` folder) `url` (sponsor website) and `bg` (card background colour, for logos with a coloured background). Sponsors are shown in the order of the list. Remove an entry to take a sponsor off the page.
